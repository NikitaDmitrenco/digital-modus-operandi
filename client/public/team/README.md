# Фотографии команды

Портреты участников команды кладутся сюда и подключаются в
`client/src/content/team.ts` полем `image` (путь от корня сайта, например
`/team/nikita.jpg`).

Ожидаемые файлы:

| Файл | Кто | Статус |
|---|---|---|
| `nikita.jpg` | Никита (D-02) | **нужно добавить** |
| `matvey.jpg` | Матвей (D-03) | **нужно добавить** |
| `arseniy.png` | Арсений (D-04) | **нужно добавить** |
| `boris.*` | Борис (D-01) | фото не предоставлено, используется плейсхолдер |

## Почему файлы понадобились заново

До переработки портреты ссылались на `/manus-storage/...`. Этот путь
обслуживается **только dev-сервером** (плагин `manus-storage-proxy` в
`vite.config.ts` ходит за файлами в builder-хранилище). В продакшен-сборку
изображения не попадают, поэтому на Vercel карточки были пустыми.

Пока файла нет, карточка автоматически показывает плейсхолдер-досье
(`onError` в `client/src/components/site/Team.tsx`) — сломанной картинки
посетитель не увидит.

Рекомендации: JPG/WebP, вертикальный кроп примерно 4:5, ширина от 640px,
вес до ~300 КБ.
