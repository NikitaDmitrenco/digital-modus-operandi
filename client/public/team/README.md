## Как готовить фото, чтобы головы стояли на одном уровне

Это главное требование к портретам: в ряду карточек макушки должны быть на
одной высоте, иначе сетка выглядит неряшливо.

Правило простое — **приводите все фотографии к одному кадру**:

- формат **720×900** (4:5);
- **макушка на 10,6% высоты кадра** — то есть примерно в 95 пикселях от
  верхнего края;
- лицо по центру по горизонтали.

Тогда `object-fit: cover` ведёт себя одинаково на всех ширинах экрана, и
головы не разъезжаются по брейкпоинтам. Сдвиг `object-position: center 10%`
задан в `client/src/index.css` один раз для всех портретов.

Если фотографию невозможно перекадрировать, в `client/src/content/team.ts`
есть поле `imagePosition` — оно перебивает общее правило для конкретного
человека (например, `imagePosition: "center 25%"`).

## Почему файлы понадобились заново

До переработки портреты ссылались на `/manus-storage/...`. Этот путь
обслуживается **только dev-сервером** (плагин `manus-storage-proxy` в
`vite.config.ts` ходит за файлами в builder-хранилище). В продакшен-сборку
изображения не попадают, поэтому на Vercel карточки были пустыми.

Пока файла нет, карточка автоматически показывает плейсхолдер-досье
(`onError` в `client/src/components/site/Team.tsx`) — сломанной картинки
посетитель не увидит.

Рекомендации: JPG/WebP, вертикальный кроп примерно 4:5, ширина от 640px,
вес до ~300 КБ.
