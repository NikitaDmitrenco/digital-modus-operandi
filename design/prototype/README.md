# Prototype handoff

Основной интерактивный референс запущен в корне WebDev-проекта и реализован в `client/src/pages/Home.tsx` вместе с `client/src/index.css`. Папка `prototype/` является handoff-зоной для следующего этапа: здесь можно хранить экспортированные standalone HTML/CSS/JS-версии, motion notes или отдельные state captures, если потребуется вынести их из React-прототипа.

В текущем референсе уже доступны desktop и mobile breakpoints, preloader, меню, scroll reveal, marquee, hover-состояния, FAQ, локальный success-state формы и reduced-motion fallback. Контент с реальными людьми, кейсами и цифрами не использовать без замены: все такие данные являются placeholder.
